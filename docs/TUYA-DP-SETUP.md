# 涂鸦 DP 点配置

对应固件 `src/master/TuyaConfig.h` 第 5 节。固件上报 11 个 DP，全部只上报（ro）。

## DP 清单

### 布尔型

| # | code | 含义 |
|---|---|---|
| 1 | `zone_a_presence` | A 防区有人 |
| 2 | `zone_b_presence` | B 防区有人 |
| 3 | `zone_c_presence` | C 防区有人 |
| 4 | `zone_d_presence` | D 防区有人 |
| 5 | `zone_a_online` | A 防区从机在线 |
| 6 | `zone_b_online` | B 防区从机在线 |
| 7 | `zone_c_online` | C 防区从机在线 |
| 8 | `zone_d_online` | D 防区从机在线 |

### 数值型

| # | code | 范围 | 间距 | 倍数 | 单位 | 含义 |
|---|---|---|---|---|---|---|
| 9 | `radar_distance` | 0 ~ 800 | 1 | 1 | 0.1m | 最近目标距离 |
| 10 | `radar_angle` | -90 ~ 90 | 1 | 1 | ° | 最近目标角度 |
| 11 | `radar_targets` | 0 ~ 3 | 1 | 1 | — | 目标个数 |

数值型的「倍数」一律填 `1`（对应接口 `scale: 0`，整数原样显示）。

## 建点步骤

### 1. 产品选项

| 项 | 值 |
|---|---|
| 设备类型 | 普通设备 |
| 通讯协议 | Wi-Fi |
| 功耗类型 | 标准功耗 |
| 智能化方式 | 自定义方案 |

### 2. 添加功能

功能定义 → 添加功能，按上面两张表逐条添加。每条填：

| 字段 | 值 |
|---|---|
| 功能类型 | 属性 |
| 功能名称 | 自定 |
| 标识符 | 表中的 `code`，必须逐字一致 |
| 数据类型 | 布尔型 / 数值型 |
| 读写属性 | 只上报 |

### 3. 发布

保存后点「发布到线上」。

## 三元组

配网页填：设备开热点 → 手机连 `Kanchuan-HB-XXXX` → 打开 `192.168.4.1` → 展开「涂鸦云三元组」→ 填 DeviceID / DeviceSecret → 保存。存 NVS，换设备不用重编译。

也可写死在 `TuyaConfig.h`：`TUYA_PRODUCT_ID` / `TUYA_DEVICE_ID` / `TUYA_DEVICE_SECRET`。NVS 优先于宏。

## 数据中心

选「中国数据中心」。选错设备不上线。

## 绑定 App

### 设备调试（现在就能用）

开发者平台 → 产品 → **设备调试** → 选中设备，可看 11 个 DP 实时值，也可手动下发模拟。不需要 App。

### 涂鸦智能 App

**扫码添加不适用本方案。** 设备没有配网环节，开机带三元组直连云 MQTT，不产生 App 配网所需的 token，所以不会出现在 App 的设备列表里。

要进 App，只有两条路：

| 路径 | 做法 | 代价 |
|---|---|---|
| 自有 App / 小程序 | 云项目 → 设备 → 关联自有 App，用 OpenAPI 拉设备列表和控制 | 要开发 App |
| 云开发 OpenAPI | 在云项目「API 调试」里搜「绑定」，用设备绑定接口把 `device_id` 绑到 App 账号的 `uid` | 要写脚本调接口 |

### 想用智能生活 App 扫码添加

必须换成 MCU 标准协议接入（ESP32 + 涂鸦 WiFi 模组 + MCU SDK 串口协议）或 TuyaOS。本固件不适用。
